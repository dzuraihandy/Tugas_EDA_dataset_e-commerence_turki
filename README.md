## 🎯 Tentang Proyek
Proyek ini mempraktikkan **Exploratory Data Analysis (EDA)** pada dataset perilaku pelanggan e-commerce. Alur kerja berfokus pada mengenali struktur data, meninjau variabel, mengolah data, dan menyampaikan temuan melalui presentasi.

## 🔎 Alur Pengerjaan
1. Meninjau dataset dan mengenali variabel yang tersedia.
2. Mengolah serta mengeksplorasi data menggunakan Microsoft Excel.
3. Merangkum hasil eksplorasi ke dalam presentasi.
4. Menyimpan dokumen agar mudah ditinjau kembali.

> Interpretasi dan angka hasil analisis sebaiknya merujuk langsung pada PDF proyek dan dataset yang disertakan.
